# prismawelt


Comments use the [prismawelt-comments giscus fork](https://github.com/prismawelt/prismawelt-comments), deployed at https://prismawelt-comments.vercel.app. The host is configured in `_config.yml` under `comments.server`; the original GitHub Discussions repository and language-independent mapping remain unchanged. The service checkout on the source laptop is `.services/comments/`, excluded from this repository. Its GitHub App credentials are managed as encrypted Vercel environment variables.
